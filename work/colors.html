Colours · Kitwork UI

Every colour a page can name.

A .ui page names a colour with a word: one of the 18 gradients built into every site, a role of the site's own palette, or one of 350 named colours. Each one below is drawn by the engine for this site, in the mode you are reading it in.

Gradients

Eighteen are built in. The first ten follow the theme: they are made of the site's roles and change with the mode. The last eight are fixed, made of named colours, the same in light and dark. A gradient is a background, background="glow", or the colour of a text, color="headline"; a site declares its own with router.gradients.

Roles

The site's own palette, declared with router.colors in its router.work. A role follows the mode: switch to dark and every swatch here changes with it. Each accent grows four rungs from its one hue: deep, soft, wash and on. A shade mixes a role toward the page, ink.70; an alpha makes it see-through, ink/80.

Named colours

350 names, each a fixed colour like white and black: the same in light and dark. A name goes wherever a colour goes, background="tomato", color="navy", border="gold", with an alpha after a slash, tomato/40. A named colour has no shades and no rungs: to have them, seed a role with it, router.colors({ brand: "cerulean" }). A site cannot name a role like a colour.

Figma · 202

The names only Figma's colour list has, lowercase and joined by hyphens: burnt-orange, rose-gold. Where Figma and CSS share a name, the CSS value is the one, so violet is #ee82ee. Five Figma names are only another name for a CSS colour and are not names here; write the CSS one: crimson-red is firebrick, grass-green is lawngreen, navy-blue is navy, purple-blue is slateblue, red-violet is mediumvioletred.
