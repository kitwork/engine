## Why this is asked for

Kitwork Engine is dual-licensed: AGPL-3.0 for everyone, and a commercial licence for organisations
that cannot ship AGPL software.

That second half only works while one party holds the rights to the whole codebase. If a
contribution arrives under the AGPL alone, that code cannot be included in a commercially licensed
build — and the project would have to either remove it, rewrite it, or track down every past
contributor for permission. All three are worse than asking once, at the start.

This is the same arrangement used by projects with the same shape. It asks you to grant rights, not
to give up yours: **you keep the copyright to your contribution.**

**7. Notification.** You will tell the project if any of the above stops being true.

## How to sign

Add your name to `CONTRIBUTORS.md` in the same pull request as your first contribution, with the
line:

```
I have read and agree to the Kitwork CLA (CLA.md).
Name · GitHub handle · date
```

For contributions made on behalf of an employer, the employer must agree separately. Write to
support@kitwork.org before opening the pull request.

## Small corrections

Fixing a typo, a broken link, or a formatting mistake does not require this agreement. If it changes
behaviour, it does.
